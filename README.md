# 👨‍💻 Eduarda Araujo 

Sou Analista de Dados & BI em transição para uma atuação híbrida entre Engenharia de Dados e Desenvolvimento Full Stack — unindo análise, automação e construção de produto.Tenho experiência prática em Business Intelligence: construção de dashboards, definição e acompanhamento de KPIs, e modelagem de dados para apoiar decisões estratégicas. Trabalho com Power BI, Excel Avançado (VBA) e dados provenientes de sistemas ERP, sempre com foco em otimizar processos e fortalecer a governança da informação.Atualmente estou expandindo minha atuação para Engenharia de Dados (SQL, Python, integração via APIs, Databricks/PySpark) e para desenvolvimento Full Stack, já aplicando essas habilidades em um projeto pessoal que une um pipeline de dados (ETL) a uma aplicação fullstack completa — do tratamento dos dados até a interface do usuário.Meu objetivo é consolidar uma carreira híbrida em dados e desenvolvimento de software, atuando em times que valorizam profissionais capazes de transitar entre análise, automação e construção de produto — gerando impacto real de ponta a ponta.
